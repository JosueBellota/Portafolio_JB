# Proyecto de Monitoreo Ambiental IoT (Biometría)

## Descripción del Proyecto
Sistema integral de monitoreo ambiental diseñado para la recolección y visualización de datos de calidad del aire (CO2, temperatura y humedad) en tiempo real. El proyecto implementa un ecosistema completo que abarca desde el hardware (nodos sensores Arduino) hasta la visualización en múltiples plataformas. Los datos son transmitidos mediante Bluetooth LE (protocolo iBeacon) a una aplicación Android, la cual actúa como puente para centralizar la información en una infraestructura en la nube. El sistema incluye un panel web administrativo y para ciudadanos que presenta mapas de calor e interpolación de datos para el análisis geográfico de la contaminación.

## Tecnologías Utilizadas

### Web Dashboard (Frontend)
* **React**: Biblioteca principal para la interfaz de usuario.
* **Leaflet & React-Leaflet**: Para la visualización de mapas interactivos e interpolación de datos (IDW).
* **Material UI (MUI)**: Para componentes de interfaz modernos y profesionales.
* **Firebase SDK**: Autenticación de usuarios y comunicación en tiempo real.

### Backend & Cloud
* **Firebase Cloud Functions (Node.js)**: API RESTful para la lógica de negocio y procesamiento de datos.
* **Firestore**: Base de datos NoSQL para el almacenamiento escalable de lecturas y perfiles.
* **Firebase Auth**: Gestión segura de identidades y roles (Administrador/Ciudadano).

### Aplicación Móvil
* **Android Studio (Java)**: Desarrollo nativo para la recepción de datos y gestión de nodos.
* **Bluetooth Low Energy (BLE)**: Escaneo y procesamiento de paquetes iBeacon.

### IoT & Hardware
* **Arduino IDE**: Programación de los nodos sensores.
* **Protocolo iBeacon**: Estándar de proximidad para la transmisión eficiente de datos ambientales.
* **Sensores de Calidad del Aire**: Integración de hardware para medición de contaminantes.
