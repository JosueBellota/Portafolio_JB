 Proyecto de Gestión de Huertos Verticales

  Descripción del Proyecto
  Plataforma web integral para la gestión y monitoreo inteligente de huertos verticales. El sistema permite a los
  usuarios administrar sus cultivos e instalaciones de forma centralizada, proporcionando herramientas visuales para el
  seguimiento de condiciones ambientales críticas. A través de una interfaz intuitiva, los usuarios pueden registrar y
  supervisar múltiples huertos, accediendo a datos históricos y en tiempo real de sensores que miden variables vitales
  como humedad, luminosidad, pH, salinidad y temperatura. El objetivo es optimizar el cuidado de los jardines verticales
  mediante la toma de decisiones basada en datos.

  Tecnologías Utilizadas

  Web Application (Frontend)
   * HTML5 & CSS3: Estructura semántica y diseño responsivo adaptado a diferentes dispositivos.
   * JavaScript (Vanilla): Lógica del lado del cliente para interactividad y manipulación del DOM.
   * Chart.js: Biblioteca de visualización de datos para la generación de gráficas interactivas de las lecturas de los
     sensores.

  Backend & Persistencia
   * PHP (Nativo): Lógica de servidor robusta para la gestión de sesiones, autenticación segura y procesamiento de
     datos.
   * MySQL: Base de datos relacional para el almacenamiento estructurado de perfiles de usuario, configuraciones de
     huertos y registros históricos de sensores.
   * MySQLi: Extensión de PHP para una comunicación segura y eficiente con la base de datos.

  Seguridad & Infraestructura
   * Autenticación Segura: Sistema de login y registro con hash de contraseñas (password_verify) y manejo de sesiones.
   * Arquitectura MVC (Simplificada): Organización del código separando lógica, vista y configuración para facilitar el
     mantenimiento.
